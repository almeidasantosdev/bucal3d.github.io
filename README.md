# Bucal3D

Site da Bucal3D Solutions, empresa criada em 2024 para clínicas odontológicas. A proposta é mostrar ao paciente, em modelo 3D, o resultado de tratamentos como alinhadores, implantes e clareamento, e também apoiar diagnóstico, próteses e material de divulgação da clínica.

Páginas estáticas em HTML e CSS:

- `index.html` — apresentação
- `Servicos.html` — planos
- `modelos3d.html` — modelos
- `Programa.html` — procedimentos
- `Login.html` e `Registre.html` — acesso e cadastro

Publicação prevista pelo GitHub Pages a partir deste repositório.
